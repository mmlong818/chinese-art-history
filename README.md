# 中国美术史

先秦至当代的可核查档案。**两代并存，当前项目是 [`wiki/`](wiki/)。**

```bash
cd wiki
python build.py                       # data/ → dist/，校验不过就不生成
cd dist && python -m http.server 8733
```

| | 第二代 · `wiki/`（当前） | 第一代 · `index.html`（冻结） |
|---|---|---|
| 形态 | 多页静态站，`data/*.json` → `build.py` | 单文件 HTML，约 8 MB，手写 |
| 实体 | **六类**：人 / 物 / 地 / 类 / 文 / 事 | 三类：画家 / 作品 / 事件 |
| 规模 | 艺术家 **1,232** · 作品 **4,962** · 遗址 150 · 类目 303 · 画论 42 · 事件 64 | 121 / 362 / 63 |
| 校验 | `schema.py` 契约 + `audit.py` 内容自检 | `tools/validate.py` |
| 状态 | 在建 | **不再新增**，保留为迁移底本 |

换架构不是因为第一代写得不好，是因为它装不下要加的东西：362 件作品零图版；
加新实体（石窟要「遗址→窟龛→单件」三级、碑刻要拓本谱系）得手工发明 HTML，没有契约可依；
认知态度寄生在 CSS class 上，无法统计也无法校验。详见 [`wiki/README.md`](wiki/README.md)。

## 这个库想做对的几件事

**不止书画。** 青铜、陶瓷、玉器、石窟、碑刻、画论同为一等实体——
因为中国美术史里最重要的部分大多无作者可指，把「作品—作者」当唯一骨架会漏掉半部史。

**断代必须交代凭据。** 每个断代块须填依据（款识／地层／碑记纪年／风格比对…）
与可靠度（确证／较可靠／存疑／不可考）。**风格比对是最弱一档，契约禁止据其判「确证」。**

**两种体裁，不是详略之别。** 条目分完整级与著录级：

- `full` 完整级——维度俱全，断言带四态，争议并陈。**有人读过材料、做过取舍。**
- `record` 著录级——只记结构化来源实际说了什么，**不写论述、不作阐释、不下四态判断。**

著录级不是完整级的残缺版，是另一种体裁。它断言得少，就不该看起来断言得多——
写了没人做过的判断，那不是补全，是造假。当前著录级占 76%，如实标注，不伪装。

**同物合并按藏品号对账，不按标题。** 标题不是稳定标识符：
「宋人／顾恺之洛神图卷」（归属写法）、「临／仿韦偃牧放图」（一字）、
「芙蓉／锦鸡芙蓉图」（词序）、「王蜀／孟蜀宫妓图」（词首）、
「挥扇／纨扇仕女图」（词中）、「仿黄公望／仿子久富春山居图」（以字代名）——
六例实测漏检，全部靠藏品号才认出是同一件物。**写错一个号比留空坏得多。**

**说清楚不知道什么。** 缺材料时写 `gap` 块说明缺什么、为何缺，而不是拿通行说法填满。
尺寸未经馆方一手核对就标待校验，不充作馆方数据；释文未核对原件就不照录，
以免把转录讹误固定成「本库释文」。

## 目录

```
wiki/               当前项目（详见 wiki/README.md）
  data/               唯一真相源：artists/ works/ sites/ classes/ treatises/ events/
  schema.py           六实体契约 + 校验器，ERROR>0 则不构建
  build.py            生成器 + 产物级断链检查
  audit.py            内容质量自检（只报告，不拦构建）
  dpm.py              故宫藏品总目抽样索引 + 藏品号对账
  verify.py           不占配额的事实核查
  dist/               产物，不入库，不手改

index.html          第一代单文件版，约 8 MB，冻结
tools/validate.py   第一代的结构校验器
tools/entry.py      第一代的条目插入器（原子替换写入）
archive/            更早的原型，不再维护
```

## 已知边界

- **深度极不平均**：著录级 3,777（76%）、完整级 1,185（23%）。
  著录级是如实标注而非欠账，**但读者须知道四分之三的条目只照录了馆方说了什么**
- **境内藏品刚过半**：境内或未定 2,758（55%）、海外 2,204（44%）。
  海外部分经决定原样保留并冻结在 `wiki/data/overseas-baseline.json`，由校验器拦住新增
- **故宫覆盖是抽样的形状，不是馆藏的形状**：`dpm.py` 缓存 80,600 号只占全库
  1,860,076 条的约 4.3%，且只扫了书画三条记录带。故本库的故宫条目以「作者已在本库
  有条目」为界，不把抽样所及者全部立目——否则覆盖只是扫描痕迹
- **1,384 条标 `memory`**，未经外部核对，其年代／尺寸／现藏应按待校验对待
- **国内馆藏普遍无自由授权图像**：石窟摩崖标 `in-situ`；书画多标 `pending`（尚未找过）
  而非 `no-free-image`（找过而无）——**两者是不同强度的断言，不可混用**
- **第一代作品层已到史实边界**：10 家确无第三件可补（作品全佚／传世仅一件／一作两本），
  名单与理由固化在 `tools/validate.py` 的 `CEILING`，**不要试图补齐**
