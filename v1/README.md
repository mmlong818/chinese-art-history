## 为什么保留

**不是留个念想。** 第二代的迁移方式是**逐条人工改写**，不做脚本抽取——
把 8 MB 手写文稿反向抽成数据是有损的。所以这份文件是迁移底本，
在改写完成之前它是已写内容的唯一记录。

原有的 `build_site_120.py` 等生成脚本早已丢失，故这一代没有整站生成器，
只有「安全地往里加一条」的能力（`tools/entry.py`）。

## 工具（仍可用）

```bash
python tools/validate.py        # 结构校验，本代的回归基线
python -m http.server 8731      # 本地预览，然后开 /index.html
```

**移动到 `v1/` 后路径仍自洽**：两个脚本都用 `dirname(dirname(__file__))` 定位仓库层，
与 `index.html` 保持同级关系，随目录整体移动而不受影响。已实测校验通过（0 errors）。

`entry.py` 的写入为**原子替换**（临时文件 + `os.replace` + 重试）：
直接 `open(...,'w')` 会立即截断原文，写到一半失败就只剩 git 能救；
且本地起预览服务器时 Windows 会锁住文件，直接写会失败——**改动前先停掉服务器。**

`validate.py` 查的东西里有两项值得记：

- **外文同形字**——曾在实体 ID 里查出西里尔 `а/н/о` 冒充拉丁 `a/n/o`，
  肉眼不可辨却使该 ID 无法检索。第二代把这条继承进了 `schema.py`
- **五处计数一致性**（图录／筛选器／朝代／卡片／侧栏）——单文件靠脚本回写维护计数，
  这正是第二代改用「数据为唯一真相源」的直接理由
