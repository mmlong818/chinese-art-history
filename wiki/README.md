## 为什么不沿用旧的单文件

仓库根目录的 `index.html`（8 MB，121 家 / 362 作品 / 63 事件）是本项目的第一代，
现冻结为**迁移底本**，不再新增。换架构不是因为它写得不好，是因为它装不下要加的东西：

- 362 件作品**零图版**。要给单文件加图，8 MB 会变成 300 MB+
- 所有计数靠脚本回写维护，这是打补丁不是架构
- **加不了新实体**。青铜器要「器类」、石窟要「遗址 → 窟龛 → 单件」三级、
  碑刻要「拓本谱系」——单文件里每加一类就得手工发明一套 HTML，没有契约可依
- 认知态度寄生在 CSS class 上，无法统计、无法校验
- 没有核查等级字段，分不出核实过的与凭记忆写的

迁移方式是**逐条人工改写**，不做脚本抽取——正因如此，当初「反向抽数据有损」的
反对理由不成立。旧文件保留不删，它是已写内容的记录。

## 六类实体

只有六类，不是十几类。靠 `work.kind` 与 `site.parent` 分派，加大足、加克孜尔不必改契约。

| 类 | 覆盖 | 分派字段 |
|----|------|---------|
| `artist` | 画家、书家、篆刻家、雕塑家 | `cat` |
| `work` | **一切单件物** | `kind`：画作/书法/篆刻/青铜/陶瓷/玉器/漆器/织绣/金银器/家具/竹木牙角/碑刻/摩崖/画像石/经幢/壁画/塑像/石雕/木雕/铜佛 |
| `site` | 遗址与窟龛，**用 `parent` 自嵌套** | — |
| `class` | 器类、窑口、书体、画科、流派、技法、纹样 | `facet` |
| `treatise` | 画论书论，既是信源也是研究对象 | — |
| `event` | 事件 | — |

青铜鼎与宋人山水都是「一件物」，区别在 `kind` 决定必备哪套维度，不是造两种实体。
石窟的三级层次这样表达：

```
site 莫高窟 → site 第 45 窟（parent: 莫高窟）→ work 西壁龛内彩塑七尊（site: 第 45 窟）
```

`work` 的维度按 kind 归成五组：**书画 / 器物 / 石刻 / 窟寺 / 雕塑**。
书画沿用旧库的十二维（它是对的）；其余按材料实情另设。

## 四种中国材料专设的块

这是本库与西洋美术史库最实质的差别。四种都是结构化数据，不是散文。

### `dating` 断代依据 — 最要紧的一项

```json
{"t": "dating", "basis": "器形序列", "conf": "较可靠", "year": "约前 1200 – 前 1100",
 "text": "…", "src": "cleveland"}
```

一件青铜器靠铭文断代、靠器形序列断代、靠共出器物断代，可靠性差三个等级；
龙门有确切造像题记的窟龛只占少数。**只填一个年份等于把三种证据抹平。**

`basis` 十档：铭文 / 碑记纪年 / 造像题记 / 款识 / 文献著录 / 器形序列 /
共出器物 / 地层 / 科技测年 / **风格比对**（本库承认的最弱一档）

`conf` 四档：确证 / 较可靠 / 存疑 / 不可考

**校验器强制：`basis` 为「风格比对」时不允许判「确证」**——最弱的依据不能自我升格。
`audit.py` 另查分布：若通篇确证占比过半即报警，因为真能确证的本来就只有那一小部分。

### `relayer` 重修层 — 窟寺必备

```json
{"t": "relayer", "when": "西夏", "what": "整壁重绘…", "evidence": "色层叠压与…"}
```

敦煌大量洞窟经西夏、元、清重绘，今天看到的画面是**叠压层**。不写清重修，
就是把后代的画当原作讲。视觉上做成横向层带，读起来像地层剖面——因为它就是。

### `rubbing` 拓本谱系 — 石刻必备

```json
{"t": "rubbing", "edition": "明拓", "holder": "…", "text": "…"}
```

碑刻的研究对象常是拓本而非原石，宋拓／明拓／清拓／近拓／**翻刻**是不同证据等级，
翻刻性质同摹本。而且**原石字口往往已弱于早拓**——研习书法该看早拓，不是看原石，
这与看画相反。视觉上做成黑底白字，因为拓本本身就是白字黑底。

### `colophon` 题跋与鉴藏

```json
{"t": "colophon", "by": "…", "when": "…", "seals": ["…"], "text": "…"}
```

一卷宋画叠着元明清历代题跋与鉴藏印，**递藏史刻在物件上**，是中国书画独有的、
可见的证据链，不是外部档案。写成散文就既查不了也统计不了。

## 核查通道

```bash
python verify.py person "八大山人"        # 生卒、别名、身份
python verify.py object "后母戊鼎"        # 年代、现藏、材质、尺寸
python verify.py holdings "ding tripod"   # 在西方馆的中国藏品（含判权与图）
```

走 urllib 直连，**不占工具配额**。子代理的检索配额一耗尽就会退回凭记忆写作，
而记忆产出的年代与尺寸在 JSON 里跟核实过的一模一样——这是最危险的失效方式，
不报错，只是悄悄变得不可信。所以撰写阶段必须永远有一条核查通道可用。

**`verification` 为必填，不设「未标」逃生口。**三档：`museum`（馆藏官方或考古报告
逐条核实）/ `wikidata`（结构化数据核过关键字段）/ `memory`（未经外部核对）。

## 取图与一个必须正视的不对称

```bash
python fetchimg.py find "ding tripod"                 # 三家馆 + Commons 一起搜
python fetchimg.py cma 136423 --id shang-ding-cma      # 克利夫兰（CC0，首选）
python fetchimg.py met 61549  --id tang-buddha-707     # 大都会亚洲部
python fetchimg.py auto <作品id> --write                # 按条目自动取
```

**两条路径，信任级别不同。**馆藏 API（克利夫兰／大都会）返回的是馆方对自己藏品的
记录——说这是商代鼎就是它库里那件，不存在同名张冠李戴，故不需作者核验。
Commons 必须核验：文件名分不出原件与摹本，也分不出器物照片与论该器物的旧书扫描页。

**实测过的两个坑**：

- **大都会 `departmentId=6` 是「亚洲部」，涵盖全亚洲**。检索 Buddha 取回的
  38165「Standing Buddha」是**泰国**造像。已加产地过滤，非中国者拒取并说明理由。
- **大都会不返回图像尺寸**。`w`/`h` 留 0 会使长宽比预留失效、图一到位版面就跳——
  而防跳动正是要求 w/h 必填的全部理由。已改为从落盘的 JPEG／PNG 头里自读，
  与克利夫兰 API 报的尺寸交叉验证一致（948×893）。

### 不对称

| 机构 | 状况 |
|------|------|
| 克利夫兰美术馆 | 完整 API · 中国部 · 多为 CC0 · 图像带宽高 ✅ |
| 大都会博物馆 | 检索 + 单件 API · isPublicDomain 判权 ✅（须过滤产地） |
| 哈佛艺术博物馆 | IIIF manifest 公开 ✅ |
| 故宫博物院 / 国博 / 数字敦煌 | **仅 HTML，无公开 API** |
| 台北故宫 / 上海博物馆 | **实测 SSL 证书链失败 / 握手超时** |

**最重要的中国文物恰在北京与台北。**后母戊鼎、《清明上河图》、汝窑天青釉洗，
既无 API 可核，也无自由授权图像；反倒是流散在西方馆的中国文物数据齐备。

所以两类分别对待：西方馆藏可标 `verification=museum` 并取图；国内馆藏记下官方
藏品页 URL 供人工核对，`verification` 最高标 `wikidata`，缺图按 `image_status`
说明原因（新增 `in-situ` 一档给石窟摩崖）。

**这个不对称是图像权属的现实，不是编纂偷懒**——不写清楚，读者会以为
「克利夫兰那件有图、故宫这件没图」是我们偷懒。

## 两把尺子

```bash
python schema.py     # 结构对不对——构建前置条件，ERROR>0 则不生成
python audit.py      # 内容像不像话——只报告，不拦构建
```

分开是因为**一份数据可以完全合规而依然很差**：每一维都在、每条都有信源、断代块也填了，
但通篇断代全标「确证」、一处 gap 也无、所有条目引同一个源——那是把表格填满了，不是档案。

`audit.py` 除通用检查外，另有三项中国材料专属：**断代健康度**（依据与可靠度分布，
确证占比过半即报警）、**拓本健康度**（只见翻刻而无早拓则提示）、
**重修健康度**（窟寺仅记一层则提示——要么真是原貌该明说，要么就是没查）。

## 分期

**9 纪元 / 17 分期**，取通行教材的章节划分并与英文通史交叉核对。两处刻意不与政权对齐：

- **五代单列一期**：五十年的重要性与政权寿命完全不成比例——山水南北两路与
  花鸟两体都在这五十年定型
- **辽金单列一期**：与两宋并行三百年，常被以中原为主轴的书写挤成脚注

**9 期标注了署名状况**，其中三条是中国材料特有的：

- **西周**：作者无名，但**器主有名**——毛公、大克靠铭文留名。这是中国美术史第一次
  能把器物系于人名之下，系的却是委作者而非制作者
- **春秋战国**：「物勒工名」出现，工匠名见于兵器量器，但那是制度性责任标记，
  不是署名意识
- **魏晋南北朝**：第一次有大量作者名，但**名与物的对应极不可靠**——顾恺之无真迹、
  《女史箴图》为唐摹、王羲之所见皆唐摹与刻帖。这与希腊雕塑只存罗马摹本同构

## 已知边界

- **内容尚在起步**：现有条目为体例样例，用以验证六实体与四种新块。
  17 期中 7 期尚无任何条目
- **`memory` 占绝大多数**：国内馆藏无 API，多数条目的年代与尺寸须人工核对馆藏页
  才能升到 `museum`。这是当前最大的质量欠账，`audit.py` 会点名
- **国内馆藏普遍无图**：石窟摩崖标 `in-situ`，书画标 `no-free-image`。
  这是授权现实，不是欠账
- **画论的版本谱系未核**：《历代名画记》等条目的版本比较尚未完成，暂不给推荐本
- 旧单文件 `../index.html` 冻结，不再新增；其内容将逐条人工改写迁入
