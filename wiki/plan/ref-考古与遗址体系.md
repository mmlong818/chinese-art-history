# 中国美术史 · 考古与遗址体系（权威清单来源）

## 0. 这份文件是什么，不是什么

它不是可以直接誊抄进 `data/sites/*.json` 的现成条目——那样做正会重蹈"记得大概写成确凿"的错误。它是**填条目前要先核对的参照表**：每处遗址列出名称、地点、年代、性质、有无正式发掘报告、所属批次或名录、确信度、本库现状、建议的嵌套层级。凡标 `[待核]` 的条目，撰写者动笔前须先查纸本或权威机构官网，不得直接采信本文件的数字与年份。

**方法与限制（如实说明）**：本会话 WebSearch 配额已耗尽。WebFetch 对 `whc.unesco.org` 官方页面两次请求均返回 403（可能是该站对自动抓取的限制），转而用 `en.wikipedia.org/wiki/List_of_World_Heritage_Sites_in_China` 与 `zh.wikipedia.org/wiki/全国重点文物保护单位` 取得部分交叉核对——这两次抓取成功且与我的记忆吻合，相关数字标注为"[记得]（经 WebFetch 交叉核对）"，比纯记忆稍强，但仍不等同一手核查，且维基百科本身也可能有误，故不升级为 `[确知]`。除此之外，石窟群、墓葬发掘报告的具体书名、年份、卷次，绝大多数只能凭已有知识作答，**大量标 `[待核]`是本文件刻意的选择，不是偷懒**。

需要立刻声明的限度：以上批次、分类、数字来自一次 WebFetch 对 zh.wikipedia 摘要页的抓取与我自身记忆的交叉核对，**不是对原始名录逐条清点**，具体到"石窟寺及石刻 307 处"这类分类计数，wikipedia 本身的表格是否完整、有无后续增补未及时更新，均未核实，故仍以 `[记得]` 而非 `[确知]` 处理。

### 1.2 《中国石窟》系列（文物出版社 / 日本平凡社）`[记得]`

这套大型考古图录丛书自 1980 年代起陆续出版，每卷对应一处或一组窟群，是石窟类目前质量最高的公开出版物之一（区别于官网介绍或旅游手册）。据我所知涉及的窟群至少包括：敦煌莫高窟（多卷）、云冈石窟、龙门石窟、麦积山石窟、炳灵寺石窟、克孜尔石窟。**具体总卷数、各卷确切出版年份、是否仍在增补，本文件不作断言，标 `[待核]`。**这套丛书应作为本库"是否有正式报告"判断的第一参照，但不能替代——它本身也有覆盖不到的窟群（如响堂山、巩县、天龙山、须弥山、剑川石钟山、安岳，据我所知均不在这套丛书之内，只能靠地方文博机构自行出版的调查报告）。

### 1.3 与 `DATING_BASIS` 的对应关系

已读 `schema.py`（`DATING_BASIS`，第 69–79 行）与 `recheck.py`（`_ceiling()`，第 88–110 行）。本库把"考古报告逐条核实"与"馆藏官方页"并列为 `museum` 档的两条路径之一，且明确"引考古期刊（`kaogu-wenwu`）不算——那是刊物不是某处的报告"（`recheck.py` 第 95 行），当前判定逻辑是看 `sources` 里是否有 ref 以 `-baogao` 结尾。**实测结果**：全库唯一登记为 `-baogao` 的 source 是 `zeng-houyi-mu-baogao`（《曾侯乙墓》1989），但本库**当前没有任何 site 条目引用它**——因为曾侯乙墓本身还没有 site 条目（见第五节缺口清单）。这意味着：**本库现有 37 处遗址，没有一处真正跨过"报告逐条核实"这一档**，全部止步于 `wikidata` 或更低。这不是本文件要修的 bug，但撰写者应当知道：新增遗址条目时，只要能确认一份正式发掘报告的存在并以 `-baogao` 后缀登记进 `sources.json`，就能把该条目的核查等级上限从 `wikidata` 提到 `museum`——这对本库遗址侧的核查等级是最直接的杠杆。

对应 `DATING_BASIS` 的十档依据：有正式发掘报告的遗址（如曾侯乙墓、满城汉墓、马王堆、殷墟妇好墓、法门寺地宫、娄睿墓、徐显秀墓、陈国公主墓）其单件出土物可以标"地层"或"共出器物"，是本库现有档位里较硬的两档；没有正式报告、只靠历代著录与传世研究建立分期的（如天龙山流散造像、何家村窖藏、部分画像石地方体系），断代多半只能落到"器形序列"甚至"风格比对"——十档里本库明确标注"风格比对"是最弱的一档（`schema.py` 第 78 行）。**这正是本文件开篇结论的另一种表述：有报告的遗址进本库能带来断代等级的真实提升，没报告的只能靠风格序列撑着，二者不该被同等对待，宜在 `sites-outline.json` 的"建议层级"之外，未来再补一列"预期可达断代等级"。**

## 七、专题一：这一侧的规模（回应问题一）

- 全国重点文物保护单位八批合计约 **5,058** 处，其中"石窟寺及石刻"一类约 **307** 处 `[记得，经交叉核对]`。
- 本库现有 **37** 处遗址条目，占石窟寺及石刻类不到 12%，若把古遗址、古墓葬也计入分母则远低于 1%。
- **《中国石窟》系列**据我所知覆盖敦煌、云冈、龙门、麦积山、炳灵寺、克孜尔等窟群，本库目前只吃下其中 4 处（敦煌、云冈、龙门、麦积山），炳灵寺、克孜尔两处**有大部头正式报告却完全没进本库**，是最容易补、性价比最高的缺口。
- 结论：本库遗址侧目前是"教材知名度驱动"的选型（四大石窟 + 大足 + 山西木构），而不是"权威名录驱动"的选型；这两种选型在教材必讲的几处高度重合，但一旦超出这几处就迅速分道扬镳。

## 八、专题二：不可移动如何进本库（回应问题二）

已读 `site.parent` 三级自嵌套机制与 `image_status` 的 `in-situ` 定义（"原址不可移动"是物的状态，"拍不到"才是缺图的理由）。据此给出分级建议：

**建议做三级嵌套的（窟龛数量大、内部差异显著、已有子窟研究传统）**：
- 莫高窟、云冈石窟、麦积山石窟、大足石刻——**本库已经这样做**，可作为后续补录的体例范本。
- 龙门石窟——**建议升级**：目前只有 longmen → longmen-fengxian 一层，应补古阳洞、宾阳中洞、万佛洞等代表窟龛。
- 克孜尔石窟、炳灵寺石窟、榆林窟——新增时应直接按三级设计（窟群 → 代表窟 → 窟内代表塑像/壁画），不要先做一级再回头拆。
- 殷墟、秦始皇陵——三级：遗址整体 → 王陵区/陪葬坑 → 代表出土器物组或代表俑坑。
- 唐陵体系——三级：唐十八陵整体 → 乾陵/懿德太子墓等 → 代表壁画或石刻。

**只需一级的（单体建筑或单一墓葬，内部无需再拆窟龛级子条目）**：
- 满城汉墓、马王堆汉墓、曾侯乙墓、法门寺地宫、陈国公主墓、娄睿墓、徐显秀墓——均为单次发掘的整体，出土物走 `work` 实体挂靠 `site` 字段即可，不必再嵌一层。
- 何家村窖藏、丁卯桥窖藏——同样一级，且应在条目里明确"窖藏"性质区别于"墓葬发掘"。
- 天龙山石窟——**特殊情形**：应做二级（天龙山 → 代表窟），但重点不在窟内配置而在"像首已散失海外"这一状态本身，与"拍不到"完全不同的另一种缺图理由，`image_status` 现有四档都不能准确覆盖这种"物已不在原址、但流散去向部分可考"的状态，建议此类条目在 `one_line` 或专门小节里显式说明，而不是勉强套用 `in-situ` 或 `lost`。

**image_status 的具体应用提醒**：露天可摄者（云冈、龙门、大足的多数龛像）不适用 `in-situ`，那是欠账；只有洞窟内部禁止摄影的（敦煌莫高窟窟内、部分麦积山窟内）才适用。新增窟群条目时要按窟龛逐一判断，不能整个窟群统一标记。

## 九、专题三："实物在语境失"一类的普遍性（回应问题三）

已读 `wanfo-si.json` 全文——它是本库第一条"寺已毁、址已失、只靠出土物反推遗址存在"的条目，条目内 `archaeology` 小节已明确写出这类条目与"有窟龛可依的石窟遗址条目在体例上的根本区别"。这一类在中国至少还有：

- **青州龙兴寺窖藏**（山东青州，1996年发现，北魏至北宋佛教造像窖藏，数量与艺术水准均高，是本库同类缺口里优先级最高的一处）`[记得]`
- **邺城北吴庄佛教造像埋藏坑**（河北临漳，2012年发现，邺城遗址范围内，数量极大）`[记得]`
- **曲阳修德寺遗址造像窖藏**（河北曲阳，1953–1954年出土，北魏至唐白石造像）`[记得]`
- **成都万佛寺遗址**——本库已有条目，本文件不重复

以上三处均属"寺院建筑本身已不存，靠历次或一次性出土的造像窖藏反推寺院曾经存在"，与万佛寺同一类型，但**具体出土年份、数量、报告出版情况，本文件一律标 `[待核]`**，需人工核实后再决定是否单独立条目还是并入已有的"南北朝佛教造像窖藏"研究框架下处理。

需要与这一类**严格区分**的，是"地方仍在、只是建筑非原构"的情形（如佛光寺、南禅寺——建筑本体虽经历代修缮但基址与主体木构仍是原物），以及"窟龛本身仍在原址、只是内部造像局部散失"的情形（天龙山，见专题二）——这三种缺图/缺语境的成因完全不同，不应用同一套 `image_status` 或同一种条目体例处理。
