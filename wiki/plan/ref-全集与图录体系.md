# 全集与图录体系：本库覆盖清单的权威参照

## 0. 确信度三档的定义（先立规矩，后写内容）

本文档几乎全部内容来自撰写者（我）自身知识，**这正是最危险的地方**——书目信息（卷数、出版年、主编、分编名称）极易「记得大概」而写成确凿。本会话 WebSearch 配额已耗尽，只能用 WebFetch 抓已知具体 URL；实际操作中，我对若干书目尝试了 `baike.baidu.com` 的条目页（猜测 URL，命中一部分，另一部分 404），核到的内容标 `[确知]`，但必须说明：**按本库 `data/sources.json` 自己的信源分级，百度百科属于第 4 级「二手转引，仅作线索与交叉参考，不单独作为事实依据」**——所以本文档里的 `[确知]` 只到「查到了、且有网页文字为证」的强度，不等于一手核实（馆藏目录、出版社官方书目、CALIS/全国图书馆联合目录）。据此实施的任何下游任务，仍应把本文档的 `[确知]` 当作「值得信但未到底」处理。

- **`[确知]`**：本次实际用 WebFetch 核到（注明来源与日期），或我对该事实有把握并能说出依据（如亲见过该出版物目录）。**本文档中出现的 `[确知]` 绝大多数属于前者，即 WebFetch 核对 baike 词条**，请勿误读为一手书目核实。
- **`[记得]`**：印象中如此，但卷数、年份、主编等细节可能有偏差，本次未核实或核实未果（含 WebFetch 404 的情况）。
- **`[待核]`**：只知道大略有这样一部书/一个类别，具体信息不可靠，必须回核纸本或权威书目库。

宁可大量标 `[记得]` `[待核]`，不把不确定的写成确凿。

## 1. 这套参照为何是本库的覆盖清单来源——它解决什么、不解决什么

**它解决的问题：** 本库现有 2,482 件作品、130 位艺术家，但骨架（`data/canon.json` 的 17 分期）与内容来源脱节——内容按「哪家博物馆 API 好用」的顺序填入，结果克利夫兰美术馆一家即占约 1,580 件（占比过半），国内馆藏仅 218 件左右。**这不是抽样偏差可以事后修正的问题，是从一开始就没有一份独立于馆藏可得性的「应该收什么」清单。**《中国美术全集》《中国美术分类全集》及其各分类全集，是新中国美术史学界在 1980 年代到 2011 年间，历时约 25 年、动员数十家出版社与上百位专家，逐类目、逐时代盘点出的覆盖框架——它们的分编/分卷结构本身就是「这个门类里，学界认为哪些东西够格入史」的显式判断。用它反查本库，能看出本库在**类目层面**（有没有这一整类）和**密度层面**（某一分期/门类下该有多少代表性单元、本库实际有几件）两个维度上的偏差，而这两个维度都不可能从博物馆 API 的响应里自己浮现出来。

**它不解决的问题：**
1. **它不解决图源问题。** 全集图录本身版权在出版社，本库不能也不应该扫描盗印其图版；全集能提供的是「应收清单」与断代/著录信息，图片仍要走本库既有的自由授权路径（Wikimedia、馆方开放数据等）。
2. **它不解决争议裁决问题。** 全集是特定时代（多数条目成于 1980～2000 年代）学界共识的固化，其分类本身也有立场（如董其昌南北宗式的框架、或某类目按政治史分期而非风格连续性分期）——本库 `dispute` 字段要处理的争议不会因为有了全集而消失，全集反而经常是「被本库标为待商榷的旧说」的原始出处之一。
3. **它不解决「境外藏品该不该收」的问题。** 全集收录以中国大陆（及台北故宫、少量境外借展）馆藏为主，本库现有内容大量来自克利夫兰、芝加哥、大都会——这些器物很多确实是重要传世品（如流失海外的宋元名迹），全集覆盖不到它们不代表本库不该收，只是不能拿全集当「排除依据」，只能当「补齐依据」。
4. **它不是本库的施工图。** 全集卷目是出版规划，不是数据模型；下一步仍需人工把「这一卷该收的代表作」翻译成本库的 `work`/`site`/`class` 条目，这一步全集帮不了忙，需另立核查任务。

### 2.2 《中国美术分类全集》——2011 年完成的更大工程

`[确知]`（WebFetch 核对 baike「中国美术分类全集」词条，2026-08-05）：

## 3. 与本库现有结构的对照

### 3.1 分期骨架（`canon.json`）vs 全集分卷

`canon.json` 的 17 分期（新石器 → 当代，9 个 era）大体对应全集类著作里「按朝代」分卷的那条轴线（2.2.1 绘画全集、2.2.4 陶瓷全集、2.5 中国美术史 都是这条轴线），**这条轴线本库已经建得比较完整，不是本次发现的缺口**。真正对不上的是另一条轴线——**全集里大量是「按类目」而非「按朝代」分卷**（2.2.3 青铜器全集的地域分卷、2.2.6 漆器全集虽仍按朝代但独立成类、2.2.10 金银玻璃珐琅器全集三个平行子类、2.3 石窟按地点分卷），本库目前没有与之对应的「类目覆盖率」视图——`class` 实体虽然存在，但校验器（schema.py）目前不强制「每个类目下应有多少代表作品」，这是纯数据模型层面的缺口，超出本文档范围，仅在此点出供后续参考。

### 3.2 `WORK_KIND_GROUP`（21～23 个 kind）vs 权威分类

`schema.py` 现有 kind：书画组（画作、书法、篆刻、版画）、器物组（青铜、陶瓷、玉器、漆器、织绣、金银器、家具、竹木牙角、珐琅）、石刻组（碑刻、摩崖、画像石、经幢、拓片）、窟寺组（壁画、塑像）、雕塑组（石雕、木雕、铜佛）——**共 23 个 kind**（书画 4 ＋ 器物 9 ＋ 石刻 5 ＋ 窟寺 2 ＋ 雕塑 3）。

第 2 节提到的权威分类中，与这 23 个 kind **对不上**的：

1. **玻璃器**——2.2.10 明确单列为与金银器、珐琅器并列的一卷，本库归入哪个 kind 都不合适（不是金银器也不是珐琅），当前**完全没有对应位置**。
2. **岩画**——2.1 提到《中国美术全集》绘画编把「岩画」与版画、年画并列单卷；本库新石器期（`neolithic`）的 `keys` 字段里只有彩陶、玉器等，完全未提岩画（阴山岩画、花山岩画、贺兰山岩画等），**既没有 kind，也没有作为 site 收录的迹象**。
3. **年画／民间美术（剪纸、皮影、玩具）**——2.1 提到绘画编「年画」单卷，我的印象（`[记得]`）中《中国美术全集》工艺美术编还有「民间玩具剪纸皮影」一卷；本库版画 kind 目前的 180 件应主要是佛经版画、小说插图、《芥子园画传》一类（据 `schema.py` 第 155 行注释），**年画、剪纸、皮影这条民俗美术支线目前应为空白或极稀疏，未实测但推断如此，`[待核]`**。
4. **建筑**——这是**结构性**而非「加一个 kind」能解决的缺口：全集设「建筑艺术编」为五编之一，与绘画、雕塑并列一等地位；本库六类实体里最接近的是 `site`（「遗址与窟龛」），但 `SITE_SECTIONS`（概览、沿革与营建、形制与布局、供养与出资、图像程式、保存与修复史、考古与著录史）明显是为**石窟寺**设计的模板（「供养与出资」「图像程式」都是石窟寺特有维度），**不适配应县木塔、故宫、苏州园林、福建土楼这类以「建筑本体形制」（斗栱、大木作、群体布局）为研究核心而非「窟龛造像题材」的对象**。若要补建筑类，不是给 `work.kind` 添词条，而要评估 `site` 模板本身是否需要一个「建筑」变体章节集。

用户任务描述里点出的「版画、珐琅、拓片」三个 kind 是清点馆藏时被动发现补上的（见 `schema.py` 注释）——**这次核对确认，若当初先有这份参照，「岩画」「玻璃器」「年画/民间美术」这三类同样本该一开始就在，且它们不是靠清点某几家馆藏样本就能发现的（岩画、民俗美术在克利夫兰/芝加哥这类西方综合馆的中国部藏品里天然稀少，只有对照国内的分类全集才会显形）**——这印证了用户「缺的是权威参照」这一判断本身。

### 3.3 `class` 的七种 facet vs 全集分类逻辑

`schema.py` 第 8 行注释列出 class 实体的七种 facet：**器类、窑口、书体、画科、流派、技法、纹样**。对照第 2 节的分类逻辑：

- 「器类」「窑口」对应 2.2.4 陶瓷全集、2.2.5 玉器全集的分类维度，**兼容**。
- 「书体」对应 2.4 书法全集的断代卷维度，**兼容**。
- 「画科」「流派」对应 2.2.1 绘画全集与 2.5 中国美术史的维度，**兼容**。
- 「技法」「纹样」对应青铜器全集、织绣全集里常见的工艺细分，**兼容**。
- **没有对应的维度**：2.2.3 青铜器全集、2.3 石窟系列常见的**地域/区系**分类（如「巴蜀系青铜器」「北方系青铜器」「陕北画像石」），以及 2.2.7 画像石全集的地域分卷逻辑。本库 `class` 的七种 facet 里没有「地域」或「窑系/器系」这一档——这是一个较小但真实的缺口，值得在下一次 schema 修订时讨论是否需要补第八种 facet，**但这已超出本文档「不动代码」的范围，仅记录不处理**。
